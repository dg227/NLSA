# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- `nlsa_models.climate.py` implements projection of xarray datasets onto principal components (e.g., kernel/Koopman eigenfunctions).
- `examples/enso/images` contains representative images generated by the ENSO KAF and Koopman scripts in that directory.
- Added a `ELNINO_2027_FROM_ERA5_NINO34SST` experiment in `examples/enso/kernel_analog_forecasting.py` that performs forecasting of the 2026/27 super El Nino using Nino 3.4 SST fields as predictor variables.

### Fixed

- Added missing cfgrib dependency in `pyproject.toml`.
- `nlsa_models.climate.make_running_pred_plotter` now labels the verification times axis with the correct timestamps and also allows forecasts to extend beyond the test data interval. 

### Changed

- Updated the Indo-Pacific SST experiment parameters in `examples/enso/koopman_diffusion_regularization_kaf.py`.
